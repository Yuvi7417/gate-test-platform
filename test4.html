• In IPv4, routers may fragment packets but they do not reassemble them. Reassembly is performed only by the final destination host after all fragments are received. This reduces processing overhead at intermediate routers. So, option (a) is correct.
• All fragments generated from the same original datagram carry the same Identification value. The destination uses this field (along with source/destination information) to group related fragments correctly before reassembly. So, option (b) is correct.

• IPv4 reassembly uses a timer mechanism. If some fragments are missing and the timer expires before all fragments arrive, the destination discards the incomplete datagram to avoid holding memory indefinitely. So, option (c) is correct.
• Fragments may travel through different network paths and can arrive in any order. The destination host uses the fragment offset field to place fragments in the correct order during reassembly. So, option (d) is incorrect.
