Q23MCQ2 MarksGATE CSE 2014 SET-3Database Management System
Consider the following relational schema:
Employee (empId, empName, empDept )
Customer (custId,custName, salesRepId, rating)
SalesRepId is a foreign key referring to empId of the employee relation. Assume that each employee makes a sale to at least one customer. What does the following query return?
SELECT empName 
FROM employee E 
 WHERE NOT EXISTS (SELECT custId
FROM customer C
WHERE C. salesRepId = E. empId
AND C. rating < > 'GOOD')
  • ANames of all the employees with at least one of their customers having a 'GOOD' rating✕ Your answer
  • BNames of all the employees with at most one of their customers having a 'GOOD' rating.
  • CNames of all the employees with none of their customers having a 'GOOD' rating.
  • DNames of all the employees with all their customers having a 'GOOD' rating.✓ Correct answer
Solution: The subquery finds this employee's customers whose rating is not 'GOOD'. NOT EXISTS keeps the employee only if there are none.

Since every employee has at least one customer, this means all of the employee's customers are rated 'GOOD'.

Answer: Names of all the employees with all their customers having a 'GOOD' rating

Q24MCQ2 MarksGATE CSE 2014 SET-2Database Management System
SQL allows duplicate tuples in relations, and correspondingly defines the multiplicity of tuples in the result of joins. Which one of the following queries always gives the same answer as the nested query shown below:
Select * from R where a in (select S. a from S)
  • ASelect R. * from R, S where R. a=S. a
  • BSelect distinct R. * from R,S where R. a=S. a✕ Your answer
  • CSelect R. * from R, (select distinct a from S) as S1 where R. a=S1.a✓ Correct answer
  • DSelect R. * from R, S where R.a = S. a and is unique R
Solution: The IN query returns each R tuple once per its own copy in R, no matter how many matching tuples S has.

- Option 1: a plain join repeats an R tuple once for every matching S tuple → \rightarrow → extra duplicates.
- Option 2: DISTINCT also removes duplicates that were genuinely in R.
- Option 3: S1 has each value of a only once, so every R tuple matches at most once → \rightarrow → same result.

Answer: Select R.* from R, (select distinct a from S) as S1 where R.a = S1.a

Q25MCQ2 MarksGATE CSE 2014 SET-1Database Management System
Given the following schema:
employees(emp-id, first-name, last-name, hire-date, dept-id, salary)
departments(dept-id, dept-name, manager-id, location-id)
You want to display the last names and hire dates of all latest hires in their respective departments in the location ID 1700. You issue the following query: 
 SQL>SELECT last-name, hire-date
FROM employees
WHERE (dept-id, hire-date) IN
(SELECT dept-id, MAx(hire-date)
FROM employees JOIN departments USING(dept-id)
WHERE location-id = 1700
GROUP BY dept-id);
What is the outcome?
  • AIt executes but does not give the correct result
  • BIt executes and gives the correct result.✓ Your answer
  • CIt generates an error because of pairwise comparison.
  • DIt generates an error because the GROUP BY clause cannot be used with table joins in a sub-query
Solution: The subquery returns, for each department at location 1700, its dept-id and latest hire date. The outer query keeps employees whose (dept-id, hire-date) pair is in that list. Multi-column IN is valid and GROUP BY works in a subquery with a join.

Answer: It executes and gives the correct result

What is SQL?

SQL is a standard language used to retrieve, insert, update, and delete  data in relational databases.

Why SQL is Used?

  • Retrieve data from  database
  • Modify existing data
  • Manage database structure

Basic SQL Commands

  • SELECT
  • INSERT
  • UPDATE
  • DELETE

SELECT Statement

  • Used to retrieve data
  • Example: SELECT * FROM Student;

WHERE Clause

  • Filters rows based on condition
  • Example: WHERE Marks > 50

JOIN Operations

  • LEFT JOIN
  • RIGHT JOIN
  • FULL JOIN

GROUP BY Clause

  • Used with aggregate functions

Aggregate Functions

HAVING Clause
