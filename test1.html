What is Normalization?

Normalization is the process of organizing data in a database to reduce redundancy and improve data integrity.

Why Normalization is Used?

  • Removes redundancy
  • Prevents anomalies
  • Improves data consistency

Types of Anomalies

  • Insertion Anomaly
  • Deletion Anomaly
  • Update Anomaly

First Normal Form (1NF)

  • No multivalued attributes
  • Atomic values only

Second Normal Form (2NF)

  • Must be in 1NF
  • No partial dependency

Third Normal Form (3NF)

  • Must be in 2NF
  • No transitive dependency

Boyce-Codd Normal Form (BCNF)

  • Stronger version of 3NF
  • Every determinant is a candidate key

Functional Dependency

  • Relationship between attributes
  • Denoted as X → Y

Decomposition

  • Lossless Join
  • Dependency Preservation

Important Concepts in Normal Form

  • Functional dependencies
  • Candidate keys
  • Decomposition rules

Applications of Normalization

  • Database design
  • Reducing redundancy
  • Improving performance

Common GATE Question Types

  • Identify highest normal form
  • Check functional dependencies
  • Decomposition problems
  • BCNF vs 3NF comparison

Common Mistakes in Normalization

  • Ignoring transitive dependency
  • Confusing 3NF and BCNF
  • Wrong decomposition

🔥 Example

If A → B and B → C, then A → C (transitive dependency).

  • This violates 3NF

🔥 3NF vs BCNF

Feature 3NF BCNF
Dependency Allows some Strict
Redundancy Less Minimal
Condition Relaxed Strict

🔥 Key Concept

  • 1NF removes repeating groups
  • 2NF removes partial dependency
  • 3NF removes transitive dependency
  • BCNF is stricter than 3NF
