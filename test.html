What is Number System?

A number system is a way of representing numbers using digits and symbols. Different number systems are used in digital electronics and computing.

Types of Number Systems

  • Binary (Base 2)
  • Decimal (Base 10)
  • Octal (Base 8)
  • Hexadecimal (Base 16)

Number System Conversions

  • Decimal to Binary
  • Binary to Decimal
  • Binary to Octal and Hexadecimal
  • Octal/Hexadecimal to Binary

Binary Arithmetic

  • Binary Addition
  • Binary Subtraction
  • Binary Multiplication
  • Binary Division

Important Concepts in Number System

  • 1’s Complement and 2’s Complement
  • Signed and Unsigned numbers
  • Overflow and underflow
  • Fixed and floating point representation

Common GATE Question Types

  • Number system conversion

Common Mistakes in Number System

Frequently Asked Questions – Number System GATE

What is binary number system?

Binary system uses base 2 and digits 0 and 1.

What is 2’s complement?

2’s complement is used to represent negative numbers in binary.

What is overflow?

Overflow occurs when result exceeds representable range.

Why is number system important?
