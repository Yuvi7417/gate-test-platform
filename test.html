Q6MCQ1 MarkISRO CSE 2020Database Management System
The SQL query
 SELECT columns
FROM TableA
RIGHT OUTER JOIN TableB
ON A.columnName = B.columnName
WHERE A.columnName IS NULL

returns the following:
  • AAll rows in Table B, which meets equality condition above and, none from Table A which meets the condition.✓ Your answer
  • BAll rows in Table A, which meets equality condition above and none from Table B, which meets the condition.
  • CAll rows in Table B, which meets the equality condition
  • DAll rows in Table A, which meets the equality condition
Solution: RIGHT OUTER JOIN keeps every row of TableB; rows with no match in TableA get NULLs for A's columns. WHERE A.columnName IS NULL keeps only those unmatched rows, i.e. rows of B that have no matching row in A.

(This question was excluded from ISRO's evaluation because of its unclear wording.)

Answer: Option 1

Q7MCQ1 MarkISRO CSE 2020Database Management System
Properties of 'DELETE' and 'TRUNCATE' commands indicate that
  • AAfter the execution of 'TRUNCATE' operation, COMMIT, and ROLLBACK statements cannot be performed to retrieve the lost  data, while 'DELETE' allow it✓ Your answer
  • BAfter the execution of 'DELETE' and 'TRUNCATE' operation retrieval is easily possible for the lost data
  • CAfter the execution of 'DELETE' operation, COMMIT and ROLLBACK statements can be performed to retrieve the lost data, while TRUNCATE do not allow it
  • DAfter the execution of 'DELETE' and 'TRUNCATE' operation no retrieval is possible for the lost data
Solution: DELETE is a DML command: it is logged row by row, so it can be rolled back before commit. TRUNCATE is a DDL command that commits implicitly, so the data cannot be recovered with ROLLBACK.

Options 1 and 3 say the same thing.

Answer: Options 1 and 3

Q8MCQ1 MarkGATE CSE 2020Database Management System
Consider a relational  database containing the following schemas.

The primary key of each table is indicated by underlining the constituent fields. 
 SELECT s.sno, s.sname
    FROM Suppliers s, Catalogue c
    WHERE s.sno=c.sno AND
        cost > (SELECT AVG (cost)
                FROM Catalogue
                WHERE pno = 'P4'
                GROUP BY pno) ;

The number of rows returned by the above SQL query is
  • A4✓ Your answer
  • B5
  • C0
  • D2
Solution: Subquery: average cost of P4 = (200 + 250) / 2 = 225.

Catalogue rows with cost > \gt > 225: (S2, P5, 250), (S3, P1, 250), (S3, P5, 300), (S3, P4, 250) → \rightarrow → 4 rows.

Each joins with exactly one supplier, and there is no DISTINCT, so 4 rows are returned.

Answer: 4

Q9NAT2 MarksGATE CSE 2019Database Management System
A relational database contains two tables Student and Performance as shown below:

The primary key of the Student table is Roll_no. For the Performance table, the columns Roll_no. and Subject_code together from the primary key. Consider the SQL query given below: 
SELECT S.Student_name, sum(P.Marks)
FROM Student S, Performance P
WHERE  P.Marks  >  84
GROUP BY S.Student_name;
The number of rows returned by the above SQL query is _________ .
Correct answer: 5
Solution: There is no join condition, so FROM makes a cross product: every student is paired with every Performance row.

WHERE Marks > \gt > 84 keeps the 5 performance rows with marks 86, 95, 90, 89, 92, and each is paired with all 5 students.

GROUP BY Student_name gives one row per student name → \rightarrow → 5 rows.

Answer: 5

Q10MCQ1 MarkISRO CSE 2018Database Management System
Consider the set of relations given below and the SQL query that follows:
 Students: (Roll_number, Name, Date_of_birth )

Coursed: (Course_number, Course_name, Instructor )

Grades: (Roll_number, Course_number, Grade)

SELECT DISTINCT Name

FROM Students, Courses, Grades

WHERE Students.Roll_number = Grades.Roll_number

                            AND   Courses.Intructor =Sriram

                            AND   Courses.Course_number = Grades.Course_number

                            AND   Grades.Grade = A
Which of the following sets is computed by the above query?
  • ANames of Students who have got an A grade in all courses taught by Sriram
  • BNames of Students who have got an A grade in all courses✕ Your answer
  • CNames of Students who have got an A grade in at least one of the courses taught by Sriram✓ Correct answer
  • DNone of the above
Solution: The joins pair each student with a grade row and its course. The conditions keep rows where the course is taught by Sriram and the grade is A. DISTINCT then lists every student with at least one such row; nothing checks "all courses".

Answer: Names of Students who have got an A grade in at least one of the courses taught by Sriram

What is SQL?

SQL is a standard language used to retrieve, insert, update, and delete data in relational databases.

Why SQL is Used?

  • Retrieve data from database
  • Modify existing data
  • Manage database structure

Basic SQL Commands

  • SELECT
  • INSERT
  • UPDATE
  • DELETE

SELECT Statement

  • Used to retrieve data
  • Example: SELECT * FROM Student;

WHERE Clause

  • Filters rows based on condition
  • Example: WHERE Marks > 50

JOIN Operations

  • INNER JOIN
  • LEFT JOIN
  • RIGHT JOIN
  • FULL JOIN

GROUP BY Clause

  • Groups rows based on column
  • Used with aggregate functions

Aggregate Functions

  • COUNT()
  • SUM()
  • AVG()
  • MAX()
  • MIN()

HAVING Clause

  • Filters groups after aggregation

Nested Queries
