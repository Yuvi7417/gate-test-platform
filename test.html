What is CPU Scheduling?

CPU scheduling is the process used by an operating system to decide which process from the ready queue should be allocated the CPU next. The goal of scheduling is to maximize CPU utilization while minimizing waiting time, turnaround time, and response time.

CPU Scheduling Algorithms

  • First Come First Serve (FCFS)
  • Shortest Job First (SJF)
  • Priority Scheduling
  • Round Robin Scheduling
  • Multilevel Queue Scheduling
  • Multilevel Feedback Queue

Comparison of CPU Scheduling Algorithms

Algorithm Type Key Feature
FCFS Non-preemptive Executed in order of arrival
SJF Preemptive / Non-preemptive Shortest job executed first
Priority Scheduling Preemptive / Non-preemptive Based on priority value
Round Robin Preemptive Time-sharing with fixed time quantum
Multilevel Queue Mixed Separate queues for process classes

Important Terms in CPU Scheduling

  • Waiting Time – Time spent by a process in the ready queue
  • Turnaround Time – Total time from submission to completion
  • Response Time – Time until first CPU allocation
  • Throughput – Number of processes completed per unit time
  • CPU Utilization – Percentage of time CPU is busy

Frequently Asked Questions – CPU Scheduling GATE

What is CPU scheduling in operating systems?

CPU scheduling is the method used by the operating system to select a process from the ready queue and allocate CPU time to it.

CPUs

Which CPU scheduling algorithms are important for GATE?

Important algorithms include FCFS, SJF, Priority Scheduling, and Round Robin.

What is the difference between preemptive and non-preemptive scheduling?

Preemptive scheduling allows interruption of a running process, while non-preemptive scheduling does not allow interruption until completion.

Why are CPU scheduling questions important in GATE?
