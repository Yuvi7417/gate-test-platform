What are Functions in C?

A function is a block of code that performs a specific task. Functions help in modular programming and can be reused multiple times.

Types of Functions

  • Library functions
  • User-defined functions

Function Components

  • Function declaration (prototype)
  • Function definition
  • Function call

Parameter Passing Methods

  • Call by Value
  • Call by Reference (using pointers)

Recursion

  • Function calling itself
  • Must have base condition
  • Used in problems like factorial, Fibonacci

Call by Value vs Call by Reference

Feature Call by Value Call by Reference
Data Passed Copy of value Address of variable
Effect on Original No change Changes reflect
Memory Separate memory Same memory reference

Important Concepts in Functions

  • Return values
  • Scope of variables
  • Static vs local variables
  • Function pointers

What is recursion?

Difference between call by value and reference?
