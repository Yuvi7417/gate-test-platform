A
The set of all strings containing an even number of b b b's.
B
The set of all strings containing the pattern b a b bab bab.
C
The set of all strings ending with the pattern b a b bab bab.
D
The set of all strings not containing the pattern a b a aba aba.
GATE CSE 2025 SET-1   Theory of Computation
Question 4 Explanation:
This DFA, on inspection of its states and transitions, is built to track only the most recently seen 3 3 3 input symbols, entering its unique accepting state precisely when those last three symbols read are exactly " b a b bab bab" — i.e. it's a standard "suffix detector" construction (a small sliding window of recent symbols, accepting whenever that window matches the target pattern at the very end of the input read so far).

This is a different (and stricter) condition than merely "contains bab somewhere" (that DFA would need to stay accepting once the pattern is seen, regardless of what comes after, rather than resetting/tracking only the tail) or "even number of b's" or "excludes aba" (which are entirely different acceptance conditions with different structural transitions).

Answer: The set of all strings ending with the pattern bab.

GATE CSE 2025 SET-1   Theory of Computation
Question 5 Explanation:
For a regular language L L L accepted by some n n n-state NFA, recall two standard facts: (1) subset construction always produces an equivalent DFA with at most 2 n 2^n 2n states, and (2) NFA/DFA state counts for a given language are not unique — smaller equivalent automata can certainly exist.

- " L L L may have an accepting NFA with < n < n <n states": could well be true (this n n n-state NFA might not be minimal), so calling it FALSE is incorrect — it's a true possibility, not a false statement.
- " L L L may have an accepting DFA with < n < n <n states": also entirely possible depending on the language, so this is also true (not false).
- "There exists a DFA with ≤ 2 n \le 2^n ≤2n states accepting L L L": guaranteed true by subset construction — so this is also true, not false.
- "Every DFA that accepts L has > 2 n > 2^n >2n states": this directly contradicts the subset-construction guarantee (a DFA with at most 2 n 2^n 2n states always exists) — so this statement is definitely FALSE.

Answer: "Every DFA that accepts L has more than 2 n 2^n 2n states" is the FALSE statement.

What is Finite Automata?

Finite Automata (FA) is an abstract machine used to recognize patterns and regular languages. It consists of states, transitions, an initial state, and final states.

ComputerScience

Types of Finite Automata

  • Deterministic Finite Automata (DFA)
  • Non-Deterministic Finite Automata (NFA)
  • ε-NFA (NFA with epsilon transitions)

Deterministic Finite Automata (DFA)

  • Exactly one transition for each input symbol
  • No epsilon transitions
  • Easy to implement

Non-Deterministic Finite Automata (NFA)

  • Multiple transitions possible
  • Can have ε-moves
  • Easier to construct

ε-NFA

  • Includes epsilon (ε) transitions
  • Moves without consuming input
  • Converted to NFA/DFA

DFA vs NFA

DFA Minimization

🔥 NFA to DFA Conversion (Subset Construction)

Steps:

  • Start with ε-closure of initial state
  • Create new DFA states as sets of NFA states
  • Repeat for all input symbols
  • Mark final states accordingly

This is one of the most frequently asked questions in GATE.

🔥 DFA Minimization Example (Concept)

  • Remove unreachable states
  • Group equivalent states
  • Merge indistinguishable states

Minimization reduces complexity and is commonly asked in exams.
