What is a Recurrence Relation?

A recurrence relation is an equation that defines a function in terms of its smaller inputs. It is commonly used to analyze recursive algorithms.

Methods to Solve Recurrence Relations

  • Substitution Method
  • Recursion Tree Method
  • Master Theorem

Master Theorem

The Master Theorem is used to solve recurrences of the form:

T(n) = aT(n/b) + f(n)

Case Condition Result
Case 1 f(n) = O(nlogba – ε) T(n) = Θ(nlogba)
Case 2 f(n) = Θ(nlogba) T(n) = Θ(nlogba log n)
Case 3 f(n) = Ω(nlogba + ε) T(n) = Θ(f(n))

Recursion Tree Method

In this method, the recurrence is expanded into a tree and the cost at each level is calculated. The total cost is obtained by summing all levels.

Substitution Method

The substitution method involves guessing the solution and proving it using  mathematical induction.

Common Recurrence Examples

  • T(n) = T(n-1) + 1 → O(n)
  • T(n) = 2T(n/2) + n → O(n log n)
  • T(n) = T(n/2) + 1 → O(log n)
  • T(n) = 2T(n/2) + n² → O(n²)

Important Concepts in Recurrence Relations

  • Divide and Conquer recurrences
  • Balanced vs unbalanced recursion
  • Tree height and cost per level
